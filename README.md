#  Counter JS

![Anteprima del progetto](./assets/images/screen-counterjs.png)

Un semplice progetto che chiedeva la realizzazione di **counter interattivo**, per verificare le skill ottenute su javascript.

---

##  Funzionalità

- Incrementa e decrementa il contatore con i pulsanti `+` e `-`  
- Interfaccia accattivante con tema **giallo/blu**
- Effetto ombra e bordi arrotondati per un look moderno
- Layout centrato e responsive

---

##  Tecnologie utilizzate

- **HTML** 
- **CSS** 
- **JavaScript**

##  Come funziona

1. Il contatore parte sempre da `0`.
2. Cliccando sul pulsante `+`, il numero aumenta di 1.
3. Cliccando sul pulsante `-`, il numero diminuisce di 1.
4. Pulsante reset che appare solo quando il contatore è maggiore di 0.
5. Cliccando il pulsante reset il contatore torna a 0.
